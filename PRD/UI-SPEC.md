# Beauty CRM｜Retention Desk UI Spec

版本：v1.1｜日期：2026-09-24｜狀態：待 Sean 確認 v3 視覺原型

## 1. 設計命題

Beauty CRM 不與 Fresha、Vagaro、Salonist 或台灣在地預約/POS 系統正面競爭。新版工作台只回答一個問題：

> 今天，哪一位客戶值得被好好記住，下一步應該做什麼？

介面主軸從「資料總覽」改為「回流決策工作台」：先排出今日要處理的客戶，再在同一畫面補足客戶記憶，最後由設計師人工核准聯絡草稿。

## 2. 競品觀察轉譯

| 競品能力 | 市場常見做法 | Beauty CRM 的取捨 |
|---|---|---|
| 預約 / POS / 付款 | Fresha、Vagaro、Salonist 與台灣產品皆完整 | 明確排除，保留既有預約工具 |
| 客戶 360° 檔案 | 歷程、偏好、過敏、表單集中 | 保留，但縮成服務當下能讀完的記憶卡 |
| 自動提醒與行銷 | 依排程大量發送訊息 | 不自動送出；先產生有脈絡的草稿再人工核准 |
| 會員 / 分眾 | 依消費、點數、方案分類 | 保留可解釋標籤，讓每個標籤都能導向下一步 |
| 多店 / 團隊 / 庫存 | 成熟產品的擴張主軸 | MVP 不做，避免稀釋療程回流價值 |
| 台灣在地通路 | LINE、訂金、電子券是常見入口 | 原型預留「複製草稿 / 開啟 LINE」動作，不假裝已整合 |

## 3. IA 與主要畫面

### 3.1 導覽

- 今日工作台：今日回流佇列、客戶記憶、下一步草稿。
- 客戶：搜尋與篩選完整客戶檔案。
- 回訪：依逾期、即將到期、已聯絡分組。
- 洞察：回訪率、回流漏斗、VIP 與流失風險。
- 設定：資料匯入匯出與提醒週期。

### 3.2 今日工作台佈局

1. Hero：一句話說明今日工作與主要 CTA。
2. KPI：待跟進、今日可回訪、近 30 日回訪率、本月服務額。
3. 回訪佇列：左側列出優先級，明示「為什麼現在要聯絡」。
4. 客戶記憶卡：右側固定顯示偏好、禁忌、最近服務與回訪理由。
5. 聯絡草稿：草稿可編輯、複製、核准；不直接自動送出。
6. 底部洞察：回流漏斗＋本週可執行清單。

## 4. 視覺系統

- 色彩：暖灰畫布、白色紙張、黑色文字、珊瑚紅作為唯一主要行動色；綠色只表示已完成，琥珀色表示即將到期，紅色表示逾期。
- 語氣：像熟悉客人的專業工作台，不像大型 ERP；避免 emoji、裝飾性漸層與不必要的圖表。
- 字體：繁體中文優先使用系統 sans；數字與英文使用等寬字體，方便讀日期、金額與週期。
- 密度：桌面版以「一眼掃完」為目標；手機版優先保留回訪佇列與客戶記憶，其他區塊可往下滑。
- 可及性：互動元素使用 button、focus-visible、aria-current、aria-live；色彩不作為唯一狀態提示。

## 4.1 既有產品不變量

- 回訪佇列預設依逾期天數由高到低排序，且保留同意狀態、可覆寫回訪日與下一步。
- 未取得行銷同意的客戶，不顯示可送出訊息的 CTA；草稿核准不等於自動發送。
- 新增服務紀錄欄位順序維持：客戶 → 服務項目 → 產品／成分 → 服務日期 → 下次回訪日 → 備註。
- 偵測到過敏或禁忌時，使用高對比警示並要求確認後才能儲存；錯誤不清除已輸入資料。
- Desktop 使用右側 drawer；Mobile 使用 bottom sheet；390px 寬度不得出現橫向溢位。

## 6. Global productisation pass（v3）

原型檔：`beauty-crm-global-v3.html`

這一版不是再做一個「暖色 CRM dashboard」，而是以可國際化的 client-retention workspace 為產品方向：

- 品牌與資訊架構：Ritual / Client retention workspace，使用 workspace switcher、窄 icon rail、client queue、client memory、next best action。
- 國際化：繁中／英文切換；文案以 retention、context、next best action 等跨市場概念表達，不綁定台灣單一通路。
- 可上線 prototype：純單檔、無外部套件；支援 localStorage 保存語言／主題／最後一筆服務、JSON 匯出、搜尋、篩選、新增服務紀錄與鍵盤快捷鍵。
- 視覺方向：中性灰底、黑色文字、電藍與薄荷綠，避開原 v2 的暖米色＋深色側欄；dark mode 以 token 切換，方便未來接產品 design system。
- 產品邊界：仍不做預約、POS、庫存或未核准自動發訊息；競品的成熟能力用作參照，不直接複製成 scope。
